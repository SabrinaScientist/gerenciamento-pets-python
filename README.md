# 🐾 Sistema de Gerenciamento de Pets

Sistema de gerenciamento de pets desenvolvido em Python, utilizando Programação Orientada a Objetos (POO), organização modular e leitura de dados em arquivo CSV.

## 🎯 Objetivo

O projeto foi desenvolvido para praticar conceitos fundamentais de Python, como criação de classes, organização do código em módulos, manipulação de arquivos e estruturas de dados em memória.

## ⚙️ Funcionalidades

- 📋 Listagem de pets cadastrados
- 🔎 Busca de pet pelo nome
- ➕ Adição de novos pets
- 📂 Leitura de dados a partir de arquivo CSV
- 💻 Interface interativa pelo terminal

## 🛠️ Tecnologias e Conceitos

- Python
- Programação Orientada a Objetos (POO)
- Classes e objetos
- Funções e módulos
- Manipulação de arquivos
- CSV
- Listas
- Estruturas condicionais e de repetição
